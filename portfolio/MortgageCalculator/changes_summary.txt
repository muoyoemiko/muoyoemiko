### Changes Summary for Calculator Project
Date: April 16, 2026

#### script.js Changes:
- **validateForm() Function**:
  - Fixed mortgage calculation formula to compute monthly payments accurately using the standard formula: Monthly Payment = PV * [r(1+r)^n] / [(1+r)^n - 1], where r = annual rate / 12, n = years * 12.
  - Changed parseInt to parseFloat for interest rate and mortgage amount to handle decimals.
  - Improved validation: Only shows errors for invalid fields; calculates and displays results only if all inputs are valid.
  - Updated postal code validation to use regex for full Canadian postal code format instead of hardcoded 'L'.
  - Added isValid flag to control flow.

- **clearErrors() Function**:
  - Simplified to directly clear all error and result elements without redundant variables.

- **New showError() Function**:
  - Added helper function to set error messages and color consistently.

- **Other**:
  - Removed showAlert() call from validateForm() to prevent premature error display.
  - Enhanced error messages for clarity (e.g., specified percentage for interest).

#### calculator.html Changes:
- **Head Section**:
  - Added meta description for SEO: "Mortgage calculator for Hamilton Homes portfolio project. Calculate monthly payments with validation."
